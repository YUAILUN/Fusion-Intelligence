# Changelog

## 1.0.0 — 2026-10-16

- First release.
- Skill: seven-step workflow (brief → panel → ground → lens passes → cross-exam → fuse → deliver), four modes
  (`quick`, `standard`, `deep`, `pantheon`).
- Library: 80 reasoning lenses in four families + 7 role lenses (evidence auditor, red team, pre-mortem,
  statistics/measurement, ethics/integrity, implementation realist, patient/practitioner voice).
- 17 panel presets for research tasks (study design, grant pre-screen, Reviewer-2, scale validation,
  prediction models, real-world databases, AI use, ethics, …).
- Fusion protocol with claim matrix, crux typing, confidence calibration and anti-patterns.
- Templates (English + 中文), research checklists, evidence-grounding rules.
- Portable install script and package validator for Claude Code, Codex and Antigravity.
