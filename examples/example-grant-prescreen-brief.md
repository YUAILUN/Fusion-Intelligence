# Example — grant pre-screen (quick mode, one-page brief)

> **Illustrative output format.** The project below is invented; no literature was searched.

**User prompt:** "Quick pre-screen: a hospital-based project to build a postoperative-delirium risk tool from our
perioperative database and test a nurse-led prevention bundle for the high-risk group."

---

**Fusion brief — delirium risk tool + nurse-led bundle** · quick · 2026-10-16
**Answer:** Fundable only after splitting two projects that are currently fused: (a) prediction-model
development/validation and (b) a trial of the bundle. As written, a weak model would define the intervention
population and a null trial would be uninterpretable.
**Confidence:** Moderate — structural problem is clear; effect sizes and local data quality are unknown.
**Panel:** `eric-s-lander` (staging) · `julie-e-buring` (design) · `R3-pre-mortem` · `R6-implementation-realist`

**Agree**
- The aims should be staged so Aim 1 pays out on its own (validated model) whatever Aim 2 shows.
- "High risk" must be defined by a pre-specified threshold tied to an action, not by the model's top decile by default.

**Split**
- *Single-site data are enough for development* vs *external validation is required before use* — crux **Methodological (M)**; resolve by
  pre-specifying temporal validation now and naming an external site in the budget.
- *Bundle fidelity can be assumed* vs *must be measured* — crux **Factual (F)**; resolve with a process-evaluation work package.

**Do now**
1. Re-scope as two linked aims with separate endpoints; make Aim 1 independently publishable.
2. Add a feasibility pilot for the bundle (adherence, workload) before the trial.
3. Define the risk threshold in terms of staff capacity (how many patients per shift can receive the bundle).

**Would change this:** the database already contains validated, complete delirium assessments for ≥ 2 years, and
a comparable external cohort is available at no cost.
**Not checked:** local data completeness, literature on bundle effectiveness, funder criteria.
